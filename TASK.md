# Задача: первый Merge Request

В репозитории лежит `calculator.py`. В нём есть баг и не хватает одной функции.

## Что нужно сделать в коде

1. Исправить функцию `subtract` — сейчас она складывает числа, а должна вычитать.
2. Реализовать функцию `divide(a, b)`:
   - возвращает результат деления `a` на `b`;
   - если `b == 0` — возвращает `None` (программа не должна падать).
3. Раскомментировать две строки с `divide` в функции `main()`.
4. Запустить `python calculator.py` и убедиться, что вывод такой:

```
2 + 3 = 5
5 - 3 = 2
4 * 3 = 12
10 / 2 = 5.0
10 / 0 = None
```

## Что нужно сделать в git

1. Склонировать репозиторий:
   `git clone <ссылка на репозиторий>`
2. Создать свою ветку (не работать в `main`!):
   `git checkout -b fix/subtract-and-divide`
3. Внести изменения и проверить, что `git status` показывает изменённый файл.
4. Сделать **два отдельных коммита**:
   - `Fix subtract function`
   - `Add divide function`
5. Отправить ветку на сервер:
   `git push -u origin fix/subtract-and-divide`
6. Открыть Merge Request из своей ветки в `main`. В описании кратко написать, что изменено.
7. Дождаться ревью и, если будут замечания, поправить их новым коммитом в ту же ветку.

## Критерии готовности

- [ ] Работа велась в отдельной ветке
- [ ] Два осмысленных коммита с понятными сообщениями
- [ ] Скрипт выдаёт ожидаемый вывод
- [ ] Merge Request создан и имеет описание
